REDGRAM+ — SITE INSTITUCIONAL
================================

COMO ABRIR NO VS CODE
1. Baixe e extraia o arquivo ZIP.
2. Abra a pasta "redgram_site" no Visual Studio Code.
3. Abra o arquivo index.html.
4. Se tiver a extensão Live Server, clique em "Go Live".
   Também é possível abrir o index.html diretamente no navegador.

ARQUIVOS
- index.html: estrutura e conteúdo do site.
- style.css: cores, layout e responsividade.
- script.js: menu, formulário de inscrição e chatbot.
- assets/logo-redgram.jpg: logo enviada.
- assets/divulgacao-redgram.jpg: arte de divulgação enviada.

ATENDIMENTO E INSCRIÇÕES
O chatbot é uma demonstração local com respostas automáticas pré-programadas.
O formulário prepara uma mensagem e abre o WhatsApp informado; a pessoa precisa
confirmar o envio no WhatsApp. Os dados não são armazenados em servidor.
